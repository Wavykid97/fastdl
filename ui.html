Send browser downloads to Laneway

Works in Chrome and Edge. Takes about a minute.

  1. In Chrome, go to chrome://extensions. In Edge, edge://extensions.
  2. Turn on Developer mode (top right in Chrome, left side in Edge).
  3. Click Load unpacked and choose Laneway's extension folder.
  4. Pin Laneway to the toolbar with the puzzle-piece button so you can switch it on and off.
